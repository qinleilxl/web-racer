# v0.7 车辆物理、碰撞与调校

本版保留 Jolt 刚体与车辆求解器，重做它上层的轮胎抓地预算、驱动配置、碰撞响应和调试入口。定位是适合键盘的半拟真驾驶：车辆通过轮胎、悬挂、动力传动、空气力和受限辅助力矩运动，正常驾驶不直接写入车身位置、朝向或速度。

## 参考范围

《巅峰极速》的公开开发访谈介绍了动力、悬挂、轮胎和车身模型的实时运算，以及面向不同平台的操作辅助。这里参考这一建模方向，结合小燕号的车型比例和现有道路进行独立实现；没有使用其专有源码、车辆数据或完整参数，也不宣称复制了它的全部物理表现。[Unreal Engine 开发者访谈](https://www.unrealengine.com/developer-interviews/racing-master-brings-authentic-racing-action-and-best-in-class-graphics-to-mobile-and-other-platforms?lang=zh-CN)

## 解算链

游戏以 120 Hz 固定步长更新物理，再对显示帧插值。每一步依次处理：

1. 平滑键盘输入、转向限幅、油门、制动和漂移收角。
2. 根据上一物理步的轮胎滚动状态计算牵引力控制与防抱死辅助，调节动力和制动力。
3. Jolt 计算发动机、自动变速箱、前后轴差速器、车轮转速与悬挂接地。
4. 轮胎回调将各轮的悬挂冲量、纵向滑移和横向滑角转换为可施加的冲量上限。
5. 施加空气阻力、下压力、风道推力及有限的车身稳定辅助；Jolt 负责接触约束和刚体运动。
6. 读取实际求解冲量、车轮接地和悬挂长度，供轮胎痕迹、车辆姿态与调试遥测使用。

Jolt 的 `TireMaxImpulseCallback` 返回的是轮胎可施加的最大冲量；实际冲量由求解器决定，因此停车时有抓地容量并不表示正在施加等大的轮胎力。[Jolt 车辆控制器文档](https://jrouwe.github.io/JoltPhysics/class_wheeled_vehicle_controller.html)

## 轮胎、悬挂与动力

- 四轮悬挂分别提供接地载荷。载荷敏感度让负载增加时的抓地增长逐渐减弱，前后及左右载荷转移会改变可用抓地。
- 纵向滑移曲线、横向滑角曲线与前后轴抓地系数共同决定轮胎能力。纵向驱动／制动和横向转弯共享摩擦椭圆预算，按测得的滑移需求分配容量；原有额外的车身横向抓地力已移除。
- 调试菜单中的轮胎 μ 是接触面的轮胎系数，乘以当前接地点的沥青或路肩倍率后参与求解，不使用引擎默认的几何平均合并方式。湿滑预设因此会同时改变驱动、转弯和制动能力。
- 摩擦椭圆以保守的逐轴冲量上限交给 Jolt，属于便于调校的组合滑移模型。它没有实现完整的轮胎温度、胎压、磨损或高阶胎体模型。
- 前后悬挂频率、防倾杆和阻尼可分别配置。车身视觉仍来自真实悬挂反馈，前轮转向和四轮滚动沿用同一物理状态。
- 发动机扭矩、主减速比、车重、重心和前轴动力分配均进入真实车辆配置。前轴分配为 0% 时后驱、100% 时前驱，中间值建立两个驱动差速器。
- TCS 根据驱动轮空转降低动力；ABS 根据各轮的带符号滑移率分别调整制动扭矩，避免一个轮子抱死就削弱四轮制动。它们是简化电子辅助，设置强度为 0 可禁用相应辅助。
- 默认前／后横向抓地为 1.2／1.4，转向横向加速度预算为 9.5 m/s²，让后轮保留更多抓地余量。驾驶辅助在普通驾驶出现约 4° 侧滑后逐渐施加有限稳定力矩，方向输入仍按当前车速控制前轮；主动漂移时该稳定力矩淡出。

松油门时通过原生轮胎制动约束提供滚动和传动阻力，低速额外提高发动机转动阻尼，以耗散起步后的残余转动能量。高速降低该阻力，漂移和收角期间按恢复权重淡出，避免抹掉侧滑惯性；没有直接归零车身速度。

水平速度低于 0.2 m/s 时将滑角视为 0：接近静止时速度方向没有意义，微小反向沉降不能被当作 180° 侧滑并持续维持收角辅助。收角完成判断也使用漂移退出滑角门槛，普通转弯的小幅侧滑不会让旧恢复权重一直保留。

## 漂移和碰撞

漂移仍保留目标滑角辅助，便于键盘点按、持续增角和反打收角。主动起漂要求一次新的 Space 输入、至少 40 km/h 向前车速及至少 25% 转向输入；支持约 0.2 秒的按键组合窗口。降至 25 km/h 以下退出主动状态。进入过实际漂移后，滑角回落至 8° 以下时也结束本次增角权限和额外转向预算，目标滑角保留角速度平滑归零；只有残余侧滑或方向输入不能再次起漂。漂移表现用实际滑角 12° 进入、8° 退出，且要求已有主动漂移状态，普通转弯和退出后的剩余收角不会重新触发漂移表现。

目标的角速度连续变化，后轮抓地按配置速度逐步恢复；收角辅助在滑角、相对偏航和后轮抓地稳定后退出。持续同向按键过量仍可能 spin。手刹力度与抓地恢复分别处理，短按 Space 使用渐变后轴制动力；连续按住约 0.12 秒后切换到与 Z 相同的四轮制动和 ABS，并切断油门及风道推力。Space 停车后保持驻车，不触发倒车。

点按空格即可起漂，松开空格后仍可用方向键维持和增加滑角。松开方向后，滑角目标带着角速度缓慢衰减，车辆保留一段惯性侧滑，再逐渐恢复抓地；反打可以更快收角。持续同向按键进入 spin 后，暂停自动扶正，保留真实旋转与滑行惯性，避免突然把车头甩回原方向。

普通键盘转向先给小幅即时响应，再随同向按键时长逐渐加深；满幅转角仍按当前车速限制。撞击中断漂移时保留按键持续状态，避免重新累计造成转向迟滞。撞停后可给油配合反向转向脱离，持续擦墙仍限速。

均衡预设的同向增角速度为 0.5 rad/s，起漂后轴抓地降低为 25%。漂移权重渐增时，前轮侧向抓地最多增加 50%，转向预算最多为普通驾驶的 2.4 倍；均通过原生轮胎冲量预算参与求解，属于适合键盘的驾驶辅助调制。保留更多后轮侧向能力，让车辆沿更小的实际弧线转弯，避免车头旋转但行驶轨迹仍向外扩张。旧版本原封不动保存的默认调校会自动升级；自定义配置和主动导入的旧数值保留。

普通驾驶前轮回中后，即使实际滑角低于漂移门槛，后驱动力仍可能维持小幅偏航。默认驾驶辅助在方向居中、前进且接地时施加受限偏航阻尼，单项力矩上限 4,500 N·m；主动漂移、收角、spin 和墙面响应期间避开该逻辑。它不改变车头全局朝向，也不直接归零速度或角速度。

v0.8.2 将轮胎恢复与收角控制权分开。主动漂移曾持有辅助控制权，实际滑角低于 3°、车身与行进方向的相对偏航低于 0.12 rad/s 且玩家再次转向时，立即结束旧反打及目标偏航的控制权；前轮仍由原转向伺服平滑跟随按键。没有新输入时保留原收角控制，待车身、滑角目标和抓地稳定后再退出。控制权交还后不会被新方向输入产生的偏航重新激活，只有新的主动漂移可以重新取得它。前后轴在剩余抓地恢复过程中保持普通驾驶比例，避免旧前轴漂移增益在交接后制造过量转向。

护墙响应使用实际碰撞面的法线求局部切线，车头跟随所接触墙面的方向变化；不再依赖赛道中心线猜测碰撞方向。碰撞点保留有限旋转响应，法线回弹按速度封顶，静止接触不主动反弹。持续擦墙逐步增加阻力并限制动力，反向转向时辅助驶离墙面。

明显撞击会中断旧的漂移目标与自动反打，前轮按当前车速重新响应方向输入；碰撞造成的侧滑不再维持旧出漂状态。轮胎抓地仍逐渐恢复，离墙并恢复抓地后可再次起漂。

车轮查询只检测地面，不把护墙顶端当作可行驶路面。道路、填平路肩与连续护墙仍使用现有碰撞几何。场外建筑和树木未变成可自由探索的物理障碍。

v0.8.3 的试车场使用原生 Jolt 实体平板，顶面在 y=0，底部延伸至 y=-2；不再用两块跨越整个场地的大三角面做悬挂查询。原网格内部对角线处曾出现假穿透和轮胎瞬间压缩，导致无可见障碍的弹跳。油漆、网格与定圆标记只有视觉作用，防护墙仍单独参与车身碰撞；普通赛道继续使用原来的地形碰撞网格。

## 调试菜单

从 v0.8 起，正常赛道不展示调试面板。主菜单按 F2，或连续点击版本号 5 次，进入 1,200 × 1,200 米的平整试车场；场内按 F2 打开侧栏。菜单打开时可以看实时遥测；需要静止观察时用“暂停试车”。Esc 优先关闭侧栏。

所有参数先进入草稿。修改数值、选择预设、导入 JSON 或恢复默认都不会立即改变正在行驶的车辆。点击“应用并重置车辆”后暂停模拟，重建试车场车辆和地面物理参数，将车放回试车起点，再由玩家继续试车。重建失败时保留旧的物理实例；浏览器存储不可用时，本次应用仍可生效。试车场不生成赛道中心线两旁的路肩和护墙，使用独立地面、外围墙与碰撞测试墙；调校完成后可返回盐风海岸。

| 参数组     | 可调内容                                                                   |
| ---------- | -------------------------------------------------------------------------- |
| 动力与车身 | 车重、扭矩、动力限速、主减速比、前轴动力比例、重心、风阻、下压力、风道推力 |
| 轮胎与制动 | 制动扭矩与前后分配、纵向和前后横向抓地、载荷敏感度、纵横耦合、TCS、ABS     |
| 悬挂与转向 | 前后悬挂频率、阻尼、防倾杆、方向响应与转向加速度预算                       |
| 漂移与辅助 | 增角、反打、回正、抓地恢复速度、后轴抓地降低、稳定辅助、手刹力度           |
| 赛道与碰撞 | 沥青与路肩抓地、重力、护墙回弹与摩擦、碰撞旋转、擦墙减速、风道能量补充     |

预设包含均衡、抓地竞速、后驱漂移和湿滑路面。它们是小燕号同一车身模型的不同调校，没有新增其他车辆外观。赛道调参改变表面与环境物理，不编辑道路路线、宽度或地形网格。

调校以版本 1 的 JSON 保存到浏览器，可以导出和导入。导入要求完整的数值字段；不兼容版本、缺字段和非有限数值会报错，超出允许范围的数值会限定到对应范围。字段说明、单位和上下限以 `src/game/Tuning.ts` 为准。

## 遥测与成绩

车身遥测包括车速、挡位、转速、滑角（°）、偏航角速度（°/s）、纵横向加速度（g）、后轮抓地恢复比例、护墙接触及碰撞法向速度。四轮分别显示接地、载荷（N）、悬挂长度、纵向滑移率、横向滑角与实际抓地使用情况。滑移率区分驱动空转和制动抱死，抓地使用情况来自求解器实际冲量。

自定义调校或圈内应用过参数会将本圈标记为调校圈，不更新个人最佳成绩。即使圈内恢复默认，该圈仍保留调校标记；恢复默认后重新开始挑战才恢复标准计时。v0.7 使用独立的最佳成绩存储项，避免与旧物理版本的成绩混比。只打开调试侧栏查看遥测不会使标准圈失效。

## 验证入口

```bash
npm test
npm run build
```

- `tests/dynamics-model.test.ts`：摩擦预算、载荷敏感度、步长一致性、墙面局部切线和有限回弹。
- `tests/tuning.test.ts`：配置往返、非法导入、范围限制、预设隔离及存储回退。
- `tests/tuning-physics.test.ts`：配置进入真实 Jolt 车辆、扭矩改变加速、路面抓地改变制动距离、各预设短时驾驶与四轮遥测、TCS／ABS 在真实空转及抱死时触发和零强度禁用。
- `tests/post-impact-steering.test.ts`：100–210 km/h 双侧漂移撞墙后，按新车速恢复前轮转角、响应反向输入，并保持渐进抓地恢复。
- `tests/grip-stability.test.ts`：60／100／160 km/h 双向持续转向、满油门、滑行、弯中制动与连续变向，共 24 组普通驾驶场景，验证侧滑、接地和车身姿态。
- `tests/steering-intent.test.ts`：25／100／250 ms 按键转角递增、点按手刹后持续增角至 spin、松键惯性，以及撞停后重新给油脱离。
- `tests/drift-entry.test.ts`：起漂输入与速度门槛、旧漂移低速退出后不能自行恢复、高速漂移显示退出后下一帧立即重新转向不能恢复漂移而新按 Space 可以、60／100／140 km/h 双向实际路径半径和横向加速度对比。
- `tests/steering-intent.test.ts` 另包含 18 组 100／140／170 km/h 点按转向后保持油门的回正验证，分别检查真实前轮转角与后续偏航角速度。
- `tests/steering-handoff.test.ts`：24 组漂移恢复直行、轮胎尚未完全恢复时重新转向的场景，检查 100／250 ms 前轮响应、真实车身偏航、连续第二次转向、松键稳定及抓地恢复连续性。
- `tests/braking-coast.test.ts`：60／100／160 km/h 制动对比、油门和加速不能覆盖手刹、驻车不倒车、10 km/h 自然滑停及高速滑行惯性。
- `tests/vehicle-feedback.test.ts`：真实 GLB 方向盘轴线、圆心和辐条运动、前轮转向及悬挂接地反馈。
- 原有物理集成测试继续覆盖漂移收角、持续 spin、高速转向、墙面碰撞与脱离、悬挂显示、赛道检查点和完整圈。

确定性测试结果用于验证固定场景中的行为边界；浏览器交互、不同设备性能和最终主观驾驶手感仍需分别验证。
