# 云岬环线 · Cloudcape Rally

一个使用项目根目录原始车辆、赛道模型制作的浏览器竞速试玩版。

## 本地游玩

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5190，选择「开始竞速」。建议使用开启硬件加速的桌面 Chrome、Edge 或 Safari。

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车，低速时倒车 |
| A / D 或 ← / → | 转向 |
| Space | 后轮手刹，辅助漂移 |
| Shift | 消耗风道能量加速 |
| R | 返回最近已通过的检查点，计时加 3 秒 |
| C | 切换近 / 远追尾镜头 |
| Esc | 暂停 / 继续 |

起步前默认驻车。绿色风旗和浅色粒子标记风道，行驶通过后补充能量。按顺序通过 7 个沿途检查点并再次穿过起终点，共 8 道计时门，即完成挑战。迷你地图上的金色圆点指向下一道门。

支持触屏方向、油门、刹车和加速按钮；当前优先调校桌面键盘体验。音效在首次点击开始后启用。

## 已实现

- React 菜单、车辆欣赏、暂停、结果页与画面 / 音量 / 镜头 / 辅助驾驶设置。
- Three.js 原始 GLB 场景和小燕号；四轮滚动、前轮转向、方向盘及真实悬挂反馈。
- 单线程 Jolt WASM，950 kg 动态车身、四轮球形扫掠悬挂、后轮驱动、自动变速、抗侧倾、道路和路边护墙碰撞。
- 固定 120 Hz 物理更新，车身 / 轮胎 / 摄像机渲染插值；正常驾驶通过轮胎、力和力矩控制，不直接修改位置或速度。
- 倒计时、带方向检测的顺序检查点、冲线结算、防跳点、重置罚时。
- localStorage 保存个人最佳成绩和设置。
- 风道收集与力驱动加速、尘土、刹车痕迹、积云、海面波光、风旗和海鸥。
- Web Audio 合成发动机、轮胎、风声、碰撞与提示音。
- 低 / 中 / 高画质控制阴影及渲染分辨率。

## 模型接入

原始 ZIP 保留不变。运行资源位于 `public/assets`：

- `Coastal_Circuit.glb`
- `Road_Collision.glb`
- `Sparrow_One_Animated.glb`
- `track_route.json`

路线资产实际为 **1,105.87 米**、8 米宽，沿用资产的真实规格，未标为方案中的 1.8 km。GLB 使用 Y 向上；路线从 Blender `[x,y,z]` 转为 `[x,z,-y]`。计时起点与模型中的棋盘格起跑线对齐（原路线采样 690），海边菜单展示车位与比赛出生位分离。

原车辆 GLB 的静态连杆缩放会使半轴和控制臂伸出轮毂，运行时依据真实车轮中心重新计算连杆朝向、长度和弹簧压缩；原模型文件未修改。车辆朝向从模型的 -X 转换为物理引擎的 +Z。

碰撞 GLB 原本仅含道路，代码另外沿路生成填平的连续路肩和无分段端面的护墙碰撞，轮胎探测只与地面碰撞、车身与护墙碰撞。护墙物理平面向上延伸到 2 米，防止车身架在可见石墙的上缘；可见石墙保持原始高度。护墙接触不施加切向摩擦，便于擦墙后脱离；场外建筑、树木不作为可探索区域，离开道路下坠会安全重置。起步、暂停、菜单与结果状态均与计时状态分开。

## 验证

```bash
npm test
npm run build
npm run preview -- --port 5191
```

测试会加载真实路面碰撞模型、启动真实 Jolt 引擎，以转向 / 油门 / 刹车控制器连续完成 **10 次独立重新起步的挑战**，每次经过全部 8 道门。还覆盖逆向 / 跳点拒绝、重置罚时、倒车、加速力、撞墙、手刹和 10 个位置的反复安全重置。新增测试还覆盖平地 0–100 加速 / 极速、100 和 160 km/h 满幅转向、漂移入弯与松开恢复、144 Hz 显示插值、整圈两侧路肩连续性、96 个贴边位置加速脱离、实际浏览器漂移撞墙场景。

这是确定性物理集成测试，不代表人工完成了 10 圈浏览器游玩，也不代表所有设备达到 60 FPS。

浏览器另行验证真实资源载入、键盘驾驶、追尾镜头、暂停与三个画质档位。v0.3 在生产预览中实测急刹 / 手刹胎迹、Shift 加速风线及漂移撞墙姿态，控制台无错误。当前没有跨浏览器基准测试或公开部署验收。

## v0.2 操控调校

- 引擎扭矩提高到 440 N·m，重新配置齿比与差速器。平地测试 0–100 km/h 约 4.2 秒，普通极速约 177 km/h；实际坡道、走线和碰撞会改变结果。
- 降低重心，按速度限制转向，增加抗侧倾、悬挂下垂行程与角速度阻尼。
- 漂移通过渐变后轴侧向抓地、有限手刹和偏航力矩进入，松开后恢复抓地；烟尘、胎痕和声音依据实际侧滑触发。
- 原模型两侧的 -30 cm 沟槽填平至路面，路肩视觉与碰撞使用相同采样；独立轮胎查询层避免把护墙当作路面。
- 120 Hz 固定物理步长与独立渲染插值，镜头跟随插值车身。

## v0.3 碰撞与速度反馈

- 护墙接触保留平移阻挡，关闭碰撞产生的旋转冲量；零反弹、零切向摩擦，擦墙时沿墙滑行。
- 护墙使用单层连续碰撞面，启用内部边缘消除；120 Hz 离散接触避免高速扫掠把三角面接缝识别成凸起。
- 漂移后轮、强力刹车四轮根据实际接地点绘制 25 cm 宽深色胎迹，贴合路面法线；固定步长生成，保留最近 8,000 段。
- 车速、加速度和 Shift 加速驱动屏幕边缘风线，加速时平滑增大视野；道路中央保持清晰，系统减少动态效果设置会减弱风线并关闭额外镜头拉伸。
- 新增 60 / 100 / 160 / 210 km/h、左右两侧、四种入射角，共 32 组真实物理撞墙测试，检查车头方向、倾斜、穿墙和小角度擦墙的沿墙速度。

## v0.4 擦墙脱离与车辆反馈

- 修正 v0.3 擦墙后的黏附：识别护墙朝向，转向驶离时减弱轮胎横向抓地与偏航阻尼，用受限力矩辅助车头回到可行驶方向，并给轻微离墙推力。车身碰撞继续阻挡平移并抑制翻转，不直接写入车身位置或速度。
- 前轮的可见转角在真实转角基础上增强，保留方向、自动回正与最大转角；物理转向仍按速度限幅，后轮不转向。
- 车身俯仰根据真实前后悬架长度差增强，表现加速抬头、刹车点头；四个轮心反向补偿车身显示变换，保持实际接地位置，弹簧、减振器、半轴和控制臂跟随轮心。
- 调整低速近镜头的距离、高度与前瞻量，让完整车身和轮胎保持在画面内。
- 新增 42 组左右两侧擦墙后持续给油或滑行、反向转向驶离的集成测试，以及原始车辆 GLB 的前轮转向、载荷转移、四轮接地测试。

## v0.5 碰撞、沿墙方向与漂移重调

- 单次撞墙有小幅法线回弹；回弹速度封顶 2.4 m/s，接触摩擦为 0.06。撞击仍抑制旋转冲量，通过受限力矩持续跟随当前位置的道路切线和曲率，车头会随着弯墙转向，反打可驶离护墙。
- 持续接触逐渐增加阻力并将动力上限降至 18 m/s，短时离墙后恢复，持续擦墙时不能用 Shift 绕过限速。HUD 会提示「擦墙减速」。左右弯墙测试从 120 km/h 开始，持续擦墙 3 秒后的最高速度约 59 km/h；具体速度随走线和接触情况变化。
- Space 起漂，A/D 按键时长逐步改变目标滑角；漂移中 100 ms 的点按可以微调，反打更快收角。不按方向时，目标滑角和后轮抓地逐步恢复，即使继续按 Space 也会回到正常行驶。松开 Space 可以更快出弯。
- 约 35–40° 是当前的可控漂移区间；持续同向长按超过抓地范围后，后轴更易失稳，可以 spin，避免辅助系统把滑角锁死。HUD 显示实际滑角，过量侧滑显示「失控」。这不是固定秒数触发的演出，初速、路面、油门和方向输入都会影响结果。
- 新增按键时长 / 60–120 Hz 一致性、漂移中点按、无方向恢复、反打救车、双向 spin、顺逆弯墙转向和持续擦墙减速测试；原有高速碰撞测试另外验证有限回弹与碰撞瞬间的车头稳定。

设计参考 [SuperTuxKart 的键盘渐变转向](https://github.com/supertuxkart/stk-code/blob/master/src/karts/controller/player_controller.cpp)、[漂移状态与转向范围](https://doxygen.supertuxkart.net/classSkidding.html) 和 [Jolt 的摩擦 / 回弹机制](https://github.com/jrouwe/JoltPhysics/blob/master/Docs/Architecture.md)。实现针对本项目 Jolt 车辆重新编写，物理正常行驶中不直接写入车身位置、朝向或速度。

## v0.6 漂移出弯衔接

- 目标滑角保留角速度，松开方向后带着惯性逐渐回正；反打通过连续变化的目标收角，避免瞬时切换。
- 后轮侧向抓地每秒最多恢复 0.4，收角辅助持续到实际滑角、相对偏航和轮胎抓地均稳定。恢复期间前轮逐渐对准行驶方向，减少突然抓地造成的反向甩尾。
- 手刹制动力与抓地恢复分开平滑释放，继续按 Space、松开方向也不会在整个收角阶段持续制动后轮。持续同向长按过量仍可 spin。
- 新增 60 / 100 / 160 km/h、左右漂移、松方向 / 松手刹 / 点按反打 / 短时持续反打，共 24 组真实 Jolt 回归场景。测试通过真实油门与变速箱加速到指定速度，检查收角惯性、抓地恢复速率、反向侧滑、后续摆动、速度保持及车身倾斜。

v0.6 在生产预览中另行验证松方向与 180 ms 反打后的收角，滑角连续减小、车身保持稳定，控制台无警告或错误。全部 21 项测试及构建通过；24 组平地出弯场景的最大反向滑角约 0.2°。这些数值仅对应固定测试场景。

## 代码

- `src/game/Physics.ts`：Jolt 世界、车辆、路面和护墙碰撞。
- `src/game/Game.ts`：主循环、驾驶状态、镜头、车辆节点更新。
- `src/game/CarRig.ts`：真实悬架数据、前轮转角、车身俯仰与连杆显示。
- `src/game/Track.ts`、`Race.ts`：路线与比赛规则。
- `src/game/Driving.ts`、`Roadside.ts`：驾驶参数 / 插值辅助与连续路肩几何。
- `src/game/World.ts`、`Audio.ts`：环境、效果和合成音效。
- `src/game/TyreMarks.ts`、`SpeedEffects.ts`：贴地胎迹和随速度变化的风线。
- `src/ui/App.tsx`、`src/style.css`：菜单、HUD、迷你地图、结果与设置。

构建产物 `dist` 可以部署到 Cloudflare Pages 或其他静态站点托管。无需后端或账号，不依赖跨域隔离和 SharedArrayBuffer。

## 当前边界

这版着重完成单人计时的可玩闭环。AI 对手、影子车、多人、车辆改装、其余三条赛道、鼠标转向和手柄输入尚未实现。画面使用原模型基础材质与风格化光照；尚未制作完整手绘贴图、精细卡通后处理或离线烘焙环境音。
